# Historial de versiones

Este documento registra los cambios, correcciones y mejoras realizadas durante el desarrollo de **SnackCheck**.

El proyecto utiliza un esquema de versionado basado en **Semantic Versioning**:

```text
MAJOR.MINOR.PATCH
```

* **MAJOR:** cambios importantes o versiones funcionales principales.
* **MINOR:** incorporación de nuevas funciones o mejoras.
* **PATCH:** correcciones menores que no alteran el funcionamiento general.

---

## Versión 1.1.0

### Documentación

* Se creó y actualizó el archivo `README.md`.
* Se agregó información sobre el propósito de SnackCheck.
* Se documentó el uso de los webhooks y la integración con Open Food Facts.
* Se añadieron instrucciones para ejecutar los casos de prueba.

---

## Versión 1.0.0

### Primera versión funcional

* Se implementó en n8n el primer prototipo funcional representado en el diagrama de flujo.
* Se configuró la recepción del código de barras mediante un webhook.
* Se incorporó la consulta de productos utilizando la API de Open Food Facts.
* Se implementaron las validaciones y respuestas principales del workflow.
